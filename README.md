## Дипломный проект. Задание 2: API тесты

### Автотесты для проверки сервиса заказа бургеров в Stellar Burgers 

### Реализованные сценарии

Созданы автотесты покрывающие следующие сценарии:

Создание пользователя: `tests/test_register_user.py`
* создать уникального пользователя;
* создать пользователя, который уже зарегистрирован;
* создать пользователя и не заполнить одно из обязательных полей.

Логин пользователя: `tests/test_login_user.py`
* логин под существующим пользователем,
* логин с неверным логином и паролем.

Изменение данных пользователя:  `tests/test_user_data.py`
* с авторизацией,
* без авторизации,

Создание заказа:  `tests/test_create_order.py`
* с авторизацией,
* без авторизации,
* с ингредиентами,
* без ингредиентов,
* с неверным хешем ингредиентов.

Получение заказов конкретного пользователя:  `tests/test_get_user_orders.py`
* авторизованный пользователь,
* неавторизованный пользователь.

### Структура проекта

- `src` - пакет, содержащий тестовые данные и вспомогательные функции
- `tests` - пакет, содержащий тесты, разделенные по классам
- `conftest.py` - содержит фикстуры pytest необходимые для тестов
- `allure-results` - Allure отчёт
- `requirements.txt` - файл зависимостей

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

Также необходим доступ к самому сервису: https://stellarburgers.nomoreparties.site/

**Запуск автотестов и просмотр Allure отчёта**

>  `$ pytest --alluredir=allure-results tests/`

>  `$ allure serve allure-results`
